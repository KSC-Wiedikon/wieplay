# Nomal

*Nomal* is Swiss German for "again".

In-house video analysis for KSC Wiedikon: coaches and players upload match and practice
footage, tag what happens, and watch clips and highlight reels, behind their Wiedisync
login. Volleyball first, basketball next. Automatic rally detection, ball and player
tracking come later as offline GPU jobs.

**Status: planning.** Nothing is built yet. Start with [`docs/PLAN.md`](docs/PLAN.md).

Related: [Wiedisync](https://github.com/KSC-Wiedikon/wiedisync), the club platform Nomal
logs in through.
